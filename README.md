# Блок Экспресс

[Играть на телефоне или компьютере](https://games.polomodov.tech/block-dash/)

Семейный раннер на трёх дорожках. Герой бежит сам, а ты выбираешь путь. Перепрыгивай низкие преграды, проскальзывай под арками и обходи высокие препятствия по соседней дорожке. Изумруды подсказывают свободный путь. После столкновения монстр-преследователь подбирается ближе. Третье столкновение завершает забег.

У маршрута нет финиша. Скорость постепенно растёт. Попробуй побить свой рекорд дистанции в каждом мире. Рекорды сохраняются в браузере на этом устройстве.

## Герои

Кирилл ускоряется на четыре секунды. Максим четыре секунды оглушает ближайших монстров. Мама становится для монстров невидимой на четыре секунды. Папино «Бу!» на три секунды распугивает монстров впереди. [Паша](https://games.polomodov.tech/block-dash/?hero=pasha) играет на гитаре, а монстры рядом пускаются в пляс на пять секунд. Способность снова готова через 30 секунд игрового времени.

## Управление

| Действие | Клавиатура | Телефон |
| --- | --- | --- |
| Смена дорожки | ← / → или A / D | Свайп влево / вправо |
| Прыжок | ↑, W или пробел | Свайп вверх |
| Подкат | ↓ или S | Свайп вниз |
| Способность | E | Кнопка способности |
| Пауза | Esc | Кнопка паузы |

Свайп вниз во время прыжка ускоряет приземление и переводит героя в подкат. На телефоне под полем также есть кнопки движения. Для прямой ссылки на выбранную пару добавь к адресу параметры `?level=end&hero=pasha`.

## Локальный запуск

Из корня репозитория выполни `python3 -m http.server 8000 --bind 127.0.0.1` и открой [локальную игру](http://127.0.0.1:8000/). Это статическая игра без установки пакетов. Для проверки правил выполни `node --test` на Node.js 22.7 или новее.

GitHub Pages публикует файлы из корня ветки `main`. Путь на семейном игровом домене обслуживает [общий Cloudflare Worker](https://github.com/polomodov/block-maze/tree/main/deploy).
